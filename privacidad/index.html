Política de Privacidad

La API de Notificaciones por Email es un proyecto académico destinado al envío de notificaciones por correo electrónico desde sistemas participantes autorizados.

1. Información que procesamos

Para prestar el servicio se procesan direcciones de correo electrónico de destinatarios, asuntos, contenidos de mensajes, identificadores de solicitudes y datos técnicos necesarios para registrar el estado de los envíos.

2. Uso de Gmail API

La aplicación utiliza Gmail API con el permiso https://www.googleapis.com/auth/gmail.send para enviar mensajes desde cuentas Gmail que han autorizado expresamente esta operación mediante OAuth 2.0.

La aplicación no solicita permisos para leer la bandeja de entrada ni para eliminar correos electrónicos.

3. Finalidad del tratamiento

Los datos se utilizan para gestionar solicitudes de envío, transmitir notificaciones, registrar resultados y gestionar reintentos ante errores de entrega.

4. Almacenamiento y seguridad

El servicio utiliza mecanismos de autenticación para restringir el acceso a los sistemas autorizados. Las credenciales OAuth deben almacenarse de forma segura y no se publican en el repositorio del proyecto.

5. Compartición de información

La información necesaria para el envío se transmite a Google mediante Gmail API. No se utiliza para publicidad ni se comercializa con terceros.

6. Conservación y eliminación

Los registros de notificaciones se conservan según las necesidades operativas del proyecto. Las autorizaciones de Gmail pueden revocarse desde la cuenta de Google.
