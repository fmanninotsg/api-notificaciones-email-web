Exomalab Avisos

Proyecto académico que permite a sistemas autorizados solicitar el envío de notificaciones por correo electrónico.

Funcionamiento

Cada sistema utiliza una clave de acceso propia. Los mensajes se envían mediante Gmail API, utilizando una cuenta remitente autorizada.

Acceso

El servicio está destinado a los grupos participantes del proyecto y no ofrece registro público.
